# Third-party sources

DFTTestVK is distributed under the GNU GPL version 3; see [LICENSE](LICENSE).
The original algorithm, transform codelets, API headers and reference binaries
have the origins listed below. Exact commits, hashes and reference versions are
recorded in [reference/source-lock.json](reference/source-lock.json).

| Material | Origin and license | Use here |
| --- | --- | --- |
| DFTTest algorithm and parameter/window definitions | [HolyWu / HomeOfVapourSynthEvolution, VapourSynth-DFTTest](https://github.com/HomeOfVapourSynthEvolution/VapourSynth-DFTTest), GNU GPL v3 | Algorithm contract, CPU numerical reference and window formulas |
| DFTTest2 fixed-size transforms and fused processing design | DFTTest2 contributors; [AliceTeaParty API4 fork](https://github.com/AliceTeaParty/vapoursynth-api4-wheels/tree/d30ef2febe1b518ff8f2eda001d1d8506dababb6/plugins/vapoursynth-dfttest2), GNU GPL v3 | GLSL adaptation of `nvrtc_source/dft_kernels.hpp`; reference CPU, NVRTC and cuFFT implementations |
| FFTW 3.3.10 generated transform codelets | [FFTW](https://github.com/FFTW/fftw3/tree/fftw-3.3.10), GNU GPL v2 or later | The DFTTest2 source identifies its codelets as FFTW derivatives; their generator commands are preserved upstream |
| VapourSynth API and Vulkan headers | [VapourSynth](https://github.com/vapoursynth/vapoursynth), LGPL v2.1 or later as stated in the headers | Build-time declarations; core functions are resolved through API tables |
| Vulkan-Headers | [Khronos Group](https://github.com/KhronosGroup/Vulkan-Headers), Apache-2.0 or MIT as stated per file | Build-time Vulkan types and function declarations |

The GLSL compute adaptation is generated by `tools/generate_shaders.py`, and
the direct and cached shader headers record their input SHA256. The maintained Vulkan code combines
the transforms with direct reflected frame loads, workgroup-wide transpose
barriers, reusable spatial half spectra, center-slice temporal inversion and
gather-based overlap-add. These
are changes to the reference code and should be reviewed as such.

and [COPYING](https://github.com/FFTW/fftw3/blob/fftw-3.3.10/COPYING) for its
complete notice and GPL v2 text. Those codelets permit use under GPL v3.

The optional `reference/backend-artifacts` directory contains downloaded
reference binaries only and is excluded from version control and plugin
installation. Its CUDA/cuFFT/runtime libraries belong to NVIDIA and are used
only for isolated reference validation and benchmarks. The Vulkan plugin does
not link them. Fetching those reference artifacts does not install them into
the user's Python environment or change VapourSynth's plugin autoload paths.
